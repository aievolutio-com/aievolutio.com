# Registro de evolución de los agentes

Este registro enlaza cambios de skills con evidencia y resultados. No se
considera mejora una instrucción nueva sin una evaluación que muestre qué
comportamiento cambia.

## Baseline 1.0.0 — 2026-10-18

- Motivo: los ocho perfiles tenían roles en código, pero carecían de capacidades
  versionadas por disciplina; la evidencia editorial reciente mostró
  repeticiones y los fallos de publicación mostraron que hacía falta aprender
  sin debilitar los controles.
- Cambio: skills explícitas para estrategia, tecnología, UX, experiencia de
  cliente, marketing, arquitectura, cambio, investigación editorial y
  razonamiento ético compartido.
- Evaluación: pruebas que verifican que cada perfil tiene una skill cargable,
  metadatos de versión, criterio de evidencia y límites; CI prueba el flujo.
- Resultado: baseline inicial. La autonomía para proponer mejoras no equivale a
  permiso para autoaprobarlas; se medirá el cambio con PRs, tests y despliegues
  validados.
