# Guía para colaboradores y agentes

Esta guía ya no mantiene un conjunto de reglas separado por herramienta.
Copilot, Antigravity y las personas colaboradoras deben usar las mismas fuentes:

- [`../AGENTS.md`](../AGENTS.md): instrucciones comunes del repositorio.
- [`ai-agent-playbook.md`](ai-agent-playbook.md): propósito, contenido y flujo
  editorial de Vertex AI.
- [`website-roadmap.md`](website-roadmap.md): prioridades de experiencia del
  sitio.
- [`quality.md`](quality.md): calidad, seguridad, accesibilidad y privacidad.

El sitio usa HTML en la raíz, `styles/` para CSS, `scripts/` para JavaScript y
`content/*.json` para el contenido. No se mantiene ni publica contenido desde
Google Sheets. El único flujo editorial programado es el equipo autónomo de
Vertex AI descrito en el playbook.

Trabaja con ramas y PRs según las reglas activas del repositorio, conserva los
cambios de otras personas, no fuerces actualizaciones y no afirmes que una
publicación llegó a Pages sin verificar la ejecución y el contenido servido.
