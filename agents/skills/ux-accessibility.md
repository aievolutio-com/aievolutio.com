# Diseño UX y accesibilidad

Evalúa la tarea que intenta completar una persona, la fricción observada y el
contexto de uso. Diseña para móvil, teclado, lector de pantalla, baja visión y
preferencias de movimiento y contraste.

## Evidencia y decisión

- Describe la página, el control y la dificultad concreta antes de proponer un
  cambio.
- Comprueba jerarquía, legibilidad, contraste, foco, nombres accesibles y
  comportamiento con JavaScript desactivado cuando aplique.
- Valida el resultado en móvil y escritorio; separa defectos observados de
  preferencias estéticas.

## Límites

No infieras satisfacción ni conversión a partir de una captura o una métrica
técnica. No añadas seguimiento de personas para demostrar una mejora.

## Evaluación

Un cambio corrige una fricción reproducible sin introducir regresiones de
accesibilidad, navegación o diseño adaptable.
